Both layouts open with the same card. In the "episodes" layout it shows the episode that is playing, which EpisodeInit.js keeps in sync with the list below by cloning the selected row.

Sorting only reorders the list. Playback keeps the order of the media items, so next/previous and auto-advance stay predictable.
No `default` for the templated labels: Fluid would read the {0}/{1} placeholders as variables. EpisodeInit.js falls back to English when an attribute comes through empty.
